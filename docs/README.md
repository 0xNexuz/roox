# Kyros documentation

Kyros is an open marketplace concept for AI inference: developers rent spare GPU capacity and pay per completed call, while providers earn from idle hardware.

The product is designed around three ideas:

1. **Choice** — select compute by model, price, latency, hardware, and region.
2. **Verification** — tie payment to a signed inference receipt instead of a provider promise.
3. **Open participation** — let independent GPU owners compete to serve requests.

{% hint style="warning" %}
Kyros is currently a frontend prototype. Wallet connection and Robinhood Chain switching work; provider data, inference execution, receipts, and settlement are simulated or planned. Do not send funds through the prototype.
{% endhint %}
